# ♠️ Family Guy Blackjack 🃏  

¡Bienvenido a **Family Guy Blackjack**!  
Un divertido juego de **Blackjack (21)** ambientado en el universo de *Family Guy*, donde Peter, Stewie, Brian y compañía te acompañan mientras intentas vencer al crupier 🕹️.

---

## 🎮 Descripción  

Este proyecto recrea el clásico juego de **Blackjack**, combinando la emoción del casino con el humor y estilo visual de *Family Guy*.  
Fue desarrollado con el objetivo de practicar lógica de programación, manipulación del DOM y diseño interactivo.  

🎯 **Objetivo:**  
Acércate lo más posible a 21 sin pasarte... o prepárate para que Peter te haga una broma por perder.

---

## 🧠 Características principales  

- ♣️ Sistema completo de Blackjack:  
  - Reparto de cartas aleatorio  
  - Cálculo automático de puntos  
  - Opciones de *Hit* (pedir carta) y *Stand* (plantarse)  
  - Determinación automática del ganador  

- 🧩 Interfaz visual inspirada en *Family Guy*  
- 😂 Frases y reacciones de personajes según el resultado del juego  
- 💾 Lógica de juego implementada 100% en JavaScript  
- 🎨 Diseño responsive con colores vibrantes estilo Quahog
